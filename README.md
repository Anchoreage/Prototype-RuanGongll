# 论证研习

法律论证标注教学原型，配套 Word 文档包含系统用例图和三个核心用例的描述表。

## 直接演示

在 GitHub 仓库中选择 **Code → Download ZIP** 并完整解压，或下载 `deliverables/法律论证标注系统项目原型.zip`。双击解压目录中的 `启动原型.cmd`。电脑需安装 Node.js 22 或更高版本，使用已编译的 `dist` 即可演示，无需安装项目依赖。打开的地址为 http://127.0.0.1:4177/ 。关闭运行窗口可停止服务。

请先完整解压，再运行解压目录内的脚本；不要直接在压缩包预览中双击。启动后保留命令行窗口。如果浏览器没有自动打开，请将窗口中显示的地址复制到浏览器地址栏。

启动失败时窗口会停留并显示 `[ERROR]`：`Node.js was not found` 表示尚未安装或未加入 PATH；`Node.js 22 or later is required` 表示版本过低；`Project files are missing` 表示解压不完整。若提示端口 4177 已使用，请关闭之前的原型运行窗口后重试。

`dist` 已随仓库提交；启动脚本按 Windows CRLF 格式保存，GitHub 下载的 ZIP 同样保留该格式。

## 核心流程

1. **指南导入**：右上角切换到“教师 / 裁定者”，打开“标注指南”。导入 `public/标注指南模板.json` 或课程指南 PDF，核对候选规则后创建新练习。PDF、DOCX、TXT 提取参考正文，须人工确认候选；JSON 导入结构化规则。扫描 PDF 不进行 OCR。
2. **命题标注**：在原文中拖选文字，选择 SF、GF、SM、GM 及适用子类型后保存。原文高亮、完整命题列表与论证图实时更新。显示编号按原文顺序重排，关系引用稳定 ID。
3. **关系构建**：选择 S、A、J、M、I。建立 J(p2,p3) 后，可将关系作为 M 的起点，继续建立 S(M(J(p2,p3),p1),p4)。重复、无效端点及不合法匹配会被阻止。
4. **关系裁定**：教师进入“关系裁定”，比较固定示例的两个独立版本，选择某个版本或输入有效表达式重标，填写裁定理由后锁定结果。
5. **学习反馈**：学生提交后查看边界、标签和关系结构差异及解释，了解本次用时，开始新的独立练习。示例演练与独立练习分别标识。

## 数据与范围

草稿及固定案例裁定记录保存在当前浏览器，刷新后恢复。支持30步撤销与重做、JSON结果导出、指南版本绑定、命题依赖关系清理。字符范围为 UTF-16 的 `[start,end)`。清理浏览器存储会清除本机草稿，需保留时请先导出。

原型使用演示角色切换，无真实账户或服务端权限。多人协作、真实独立版本上传与对齐、任务批量分配、Excel导出与受控修订未实现。标准答案与裁定案例取自课程指南示例；PDF文件名写v1.2，正文声明v1.1，按正文版本使用。合同及合同解释采用SM-C。

## 开发与构建

需要 Node.js 22+。运行 `npm install`，再运行 `npm run dev`。运行 `npm run build` 更新 `dist`。采用 React + Vite；文件内容只在本机浏览器处理。PDF读取器、DOCX解压库按需加载。

源代码按工作台、指南、论证图、裁定与反馈分组件。配套文档生成脚本在 `tools/build_document.py`，需 Python、python-docx 和 Pillow；文档位于 `deliverables`。
